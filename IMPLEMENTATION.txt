📡 ENDPOINTS PRINCIPAIS
═══════════════════════

AUTENTICAÇÃO
  POST   /api/auth/login              - Fazer login
  GET    /api/auth/me                 - Dados do admin (protegido)
  POST   /api/auth/register           - Registrar novo admin

PETS
  GET    /api/pets                    - Listar (com paginação)
  GET    /api/pets/:id                - Obter um
  POST   /api/pets                    - Criar (protegido)
  PUT    /api/pets/:id                - Atualizar (protegido)
  DELETE /api/pets/:id                - Deletar (protegido)
  POST   /api/pets/:id/photo          - Upload de foto (protegido)
