  5 minutos para entender tudo


PASSO 2: Escolha uma opção

  OPÇÃO A - Docker Compose (Recomendado)
  ──────────────────────────────────────
  $ docker-compose up
  $ curl http://localhost:8080/api/pets
  ✅ Pronto em 30 segundos!

  OPÇÃO B - Local (sem Docker)
  ───────────────────────────
  $ python -m venv venv
  $ source venv/bin/activate
  $ pip install -r requirements.txt
  $ cp .env.example .env
  $ python seed.py
  $ python app.py
  ✅ Pronto em 2 minutos!

  OPÇÃO C - Cloud Run (Produção)
  ─────────────────────────────
  $ gcloud auth login
  $ gcloud config set project seu-project-id
  $ ./deploy.sh seu-project-id
  ✅ Rodando em produção!


PASSO 3: Teste os endpoints
───────────────────────────

  $ curl -X POST http://localhost:8080/api/auth/login \
    -H "Content-Type: application/json" \
    -d '{"email":"admin@example.com","password":"admin123"}'

  $ curl http://localhost:8080/api/pets

📊 ENDPOINTS DISPONÍVEIS
═══════════════════════════════════════════════════════════════════════════

AUTENTICAÇÃO
  POST   /api/auth/login              Fazer login → JWT token
  POST   /api/auth/register           Registrar novo admin
  GET    /api/auth/me                 Dados do admin (protegido)

PETS - LEITURA
  GET    /api/pets                    Listar (paginado)
  GET    /api/pets/:id                Obter um pet

PETS - ESCRITA (protegido com JWT)
  POST   /api/pets                    Criar novo pet
  PUT    /api/pets/:id                Atualizar pet
  DELETE /api/pets/:id                Deletar pet

PETS - MÍDIA
  POST   /api/pets/:id/photo          Upload de foto

HEALTH & STATUS
  GET    /health                      Health check
  GET    /live                        Liveness probe
  GET    /                            Root endpoint
