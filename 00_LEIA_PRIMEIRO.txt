🚀 COMO COMEÇAR AGORA
════════════════════════════════════════════════════════════════════════════

OPÇÃO 1: Docker Compose (Recomendado - 30 segundos)
──────────────────────────────────────────────────
  $ cd adocao-gatos
  $ docker-compose up
  
  # Aguarde 10 segundos
  # Abra: http://localhost:8080/api/pets
  
  ✅ Pronto!


OPÇÃO 2: Local sem Docker (2 minutos)
──────────────────────────────────────
  $ python -m venv venv
  $ source venv/bin/activate              # Windows: venv\Scripts\activate
  $ pip install -r requirements.txt
  $ cp .env.example .env
  $ # Edite .env com suas credenciais PostgreSQL
  $ python seed.py
  $ python app.py
  
  ✅ Pronto!


OPÇÃO 3: Cloud Run (5 minutos)
──────────────────────────────
  $ gcloud auth login
  $ gcloud config set project seu-project-id
  $ ./deploy.sh seu-project-id
  
  ✅ Pronto em produção!
